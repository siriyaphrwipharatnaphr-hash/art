THE ART ARCHIVE — starter website
====================================

ไฟล์หลัก: index.html

วิธีแก้:
- เปิด index.html ด้วย VS Code / Notepad++ / โปรแกรมแก้โค้ด
- แก้ข้อความใน <body>
- แก้สีได้ที่ส่วน :root ด้านบนของ <style>
- แก้โลโก้ตรง THE ART ARCHIVE
- เปลี่ยนรูป placeholder เป็น <img src="..."> ได้
- แต่ละหมวดในโปรเจกต์จริงควรแยกเป็นไฟล์ HTML คนละหน้า

หมายเหตุ:
นี่เป็น starter front-end สำหรับนำไปต่อยอด ไม่ใช่ระบบฐานข้อมูล/แอดมินจริง
ระบบกระทู้ แชท การอัปโหลดภาพ และ Admin จำเป็นต้องมี backend/database ก่อนใช้งานจริง
